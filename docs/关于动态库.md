# 关于动态库

当前 reset 后只保留 `CameraCapture`，但它仍然依赖 Luckfox/Rockchip 的运行时库。

`CMakeLists.txt` 中当前链接的库：

```cmake
set(MPI_LIBS
    sample_comm
    rockit
    rockchip_mpp
    rkaiq
    rga
    pthread
    dl
)
```

这些库来自：

```text
3rdparty/luckfox_pico_rkmpi_example/lib/uclibc
```

部署到开发板时，通常需要把相关 `.so` 复制到设备的 `/usr/lib/`：

```bash
scp 3rdparty/luckfox_pico_rkmpi_example/lib/uclibc/*.so root@<开发板IP>:/usr/lib/
scp 3rdparty/luckfox_pico_rkmpi_example/lib/uclibc/*.so.1 root@<开发板IP>:/usr/lib/
```

检查动态库解析：

```bash
ldd CameraCapture
```

后续重新引入 VENC、RTSP、RGA 或 NPU node 时，再按实际目标补充链接库和部署说明。
